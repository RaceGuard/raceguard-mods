# RaceGuard Mods Examples

模板和参考实现. 看哪个看你想干什么:

```
examples/
├── cars/
│   ├── nissan_gtr_r35/   ← 完整 GT-R 适配 (实车验证, 含 PID bitmap + DTC)
│   └── bmw_template/     ← BMW 起步模板 (从这复制改自己的车)
└── themes/
    └── dark_minimal/     ← 主题包 demo (FS uploadfs 流程演示)
```
